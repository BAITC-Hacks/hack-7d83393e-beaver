## Команды и артефакты
- python scripts/verify_reference.py → reports/reference-results.json, reference-junit.xml.
- python -m evidence_core serve --port 8765 → настоящий HTTP health-проход.
- python scripts/browser_component_check.py → reports/browser-component-results.json,
  ui-reference.png и скачанный DOCX. В этом тесте fetch заменён транспортным
  адаптером к реальному ASGI-приложению. Это не сетевой браузерный E2E.
- DOCX отрендерен штатным инструментом среды; изображения проверены визуально.

Попытка стандартного playwright install chromium не удалась из-за DNS
(EAI_AGAIN); для компонентного теста использован уже установленный Chromium.
Ограничения сети и браузерные политики не изменялись.
