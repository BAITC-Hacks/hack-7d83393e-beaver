# Агент E — опциональная камера, только после готовности основы
Прочитай AGENTS.md и API.md. Меняй services/vision.py и vision-тесты.
Предположения теста: неподвижная камера, 2–3 заранее размеченные зоны мест,
согласие участников. YOLO с локальным файлом весов, ByteTrack без ReID.
Обнаруживай person и количество видимых объектов. Для зон возвращай visible,
not_observed, unknown. Предложи интервалы для добровольного catch-up.
Начальная настройка гистерезиса: not_observed после 8 секунд, visible после
2 секунд наблюдения. Это проверяемые параметры, не доказанные значения.
Потеря детекции не доказывает выход; перекрытие/сбой камеры — unknown.
Смена места отменяет персональное сопоставление до повторного подтверждения.
Камера не узнаёт личность; ручная привязка места действует только в одной сессии.
Не делать распознавание лиц, эмоции, внимание, рейтинги, подсчёт уникальных
посетителей по track_id. Не сохранять видео по умолчанию.
При реальной демонстрации синхронизируй камеру и аудио относительно одного t0.
Загруженный файл не смешивай с несинхронизированной живой камерой.
Невыполненный модуль скрывается флагом, а не имитируется фиксированным счётчиком.
