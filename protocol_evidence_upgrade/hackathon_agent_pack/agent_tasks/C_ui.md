# Агент C — интерфейс защиты
Прочитай AGENTS.md и API.md. Меняй только static/ и ui-тесты.
Одна локальная страница HTML/CSS/JS, никаких CDN, внешних шрифтов и аналитики.
Экраны/секции: запись или загрузка; участники; прогресс этапов; аудио/транскрипт;
карточки поручений; вопросы для уточнения; история; саммари; DOCX.
Клик по основанию поручения переводит локальный плеер к нужному start_ms.
Показать связь speaker_id с человеком и явное подтверждение секретарём.
Поля не определены — заметная маркировка, а не пустота без пояснения.
Состояния: loading, error, empty, draft, approved. Отдельный баннер FIXTURE,
если показывается пример. Не симулируй процент точности, live-обработку,
отправленное уведомление или успешный экспорт.
Панель камеры опциональна, скрывается конфигурацией. В ней нет рейтингов людей.
Catch-up: пользователь подтверждает/выбирает интервал и нажимает кнопку.
Тест: загрузить короткий файл, исправить ответственного, открыть реплику,
просмотреть историю, выгрузить DOCX. При backend-ошибке показать причину.
