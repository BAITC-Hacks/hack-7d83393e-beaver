# Агент A — локальная речь и говорящие
Прочитай AGENTS.md, AUTONOMOUS_SETUP.md и API.md.
С интегратором подготовь доступные веса: он владеет общими загрузками,
конфигурацией и средой, ты реализуешь подготовку речевых моделей и smoke-tests.
Отсутствие весов — повод скачать их на этапе BOOTSTRAP_ONLINE, не завершить работу.
Если gated-доступа к pyannote нет, исследуй доступный локальный вариант настоящей
диаризации и согласуй его с интегратором. Права доступа не обходить. Меняй только services/speech.py и speech-тесты.
Реализуй настоящий faster-whisper из локального пути + pyannote community-1
из локального пути. Не скачивай веса автоматически при обработке.
Сопоставь интервалы диаризации с репликами по времени; спорное сопоставление
оставь неопределённым. Сохрани исходные язык, текст и метки времени.
Верни speaker_id без выдуманных ФИО. Поддержи список обнаруженных голосов для
подтверждения секретарём. Если один сегмент пересекает несколько голосов,
разбивай только с подходящими временными метками; иначе добавляй warning.
Тесты: короткая реальная запись, пустой файл, нет модели, несколько голосов,
смешанная речь. Эталоны fixtures не являются распознанным результатом.
Сообщи измеренное время на фактическом устройстве, ошибки и команды запуска.
