# Сценарий защиты

Это предлагаемый сценарий; ни запись, ни работающая модель в комплект не входят.
Все имена и задачи вымышлены. Казахские реплики перед записью желательно
проверить с носителем. Отдельно записать RU, KK и MIX, а не только один пример.

## Основной эпизод
Совещание: 23 сентября 2026 года, Asia/Almaty.
Руководитель: «Данияр, отчётты жұмаға дейін жіберіңіз».
Данияр: «К пятнице не успею. Предлагаю в понедельник, 28 сентября, до 12:00».
Руководитель: «Да, согласовано: 28 сентября до 12:00».
Айдана: «Ещё нужно проверить интеграцию».

Ожидаемо: отчёт — одно поручение Данияру, срок 28 сентября 12:00,
старый срок в истории. Проверка интеграции — кандидат без ответственного
и срока; интерфейс задаёт два вопроса. Эти результаты — эталон, не измерение.

## Защита, около 3 минут
- Коротко объяснить: «Не просто записываем речь — сохраняем договорённости».
- Показать, что локальные модели действительно обрабатывают запись. Если
  вычисление длиннее выступления, честно показать реальный статус и отдельно
  сохранённый результат предыдущего прогона с тем же файлом/версиями.
- Открыть историю срока и исходные реплики; показать, что задача не удвоилась.
- Показать вопросы по отсутствующим реквизитам и ручное подтверждение.
- Выгрузить DOCX и открыть документ; показать казахский текст.
- Опционально показать catch-up по согласованному интервалу камеры.
- Показать запуск без внешней сети и README с пройденными/непройденными пунктами.

## Честные формулировки
«Пакетная обработка после записи» вместо «реальное время», если это так.
«Не наблюдался в заданной зоне» вместо «не слушал».
«Секретарь подтвердил голос» вместо «ИИ узнал человека по лицу».
«Эталонный пример интерфейса» вместо «модель сейчас распознала», если это fixture.
